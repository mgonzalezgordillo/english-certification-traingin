# Roadmap

## Phase 1: MVP Foundation (Current)
- Initialize project and architecture.
- Set up domain types and Dexie DB.
- Create dashboard shell and navigation.
- Implement seed data and AI abstraction.

## Phase 2: Core Training Modules
- Build out the Vocabulary Library.
- Implement Flashcards with Spaced Repetition (SRS).
- Build the Grammar Library.

## Phase 3: Skill Trainers
- Reading Trainer.
- Listening Trainer.
- Writing Trainer (with optional AI feedback).
- Speaking Trainer (audio recording + playback).

## Phase 4: Analytics & Exam Mode
- Analytics Dashboard implementation (Recharts).
- Error & Weakness Analysis.
- Configurable Linguaskill Simulator.

## Phase 5: Polish & Sync
- Comprehensive adaptive engine based on history.
- Cloud sync (optional).
